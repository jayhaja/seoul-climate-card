저장소에는 OD 단위 주별 이용자 수와 이를 재구성할 수 있는 파일(OD별 효과, 출발지 구성표, 여의도 OD의 관측·합성 주별 경로 CSV)을 넣지 않습니다. figures/의 그림(여의도 OD 경로 그림 포함)은 반출 승인 범위입니다. 원자료는 자료 제공기관에 이용 신청할 수 있습니다.The repository excludes OD-level weekly counts and any file that would reconstruct them (per-OD effects, origin membership tables, observed/synthetic weekly path CSVs for the Yeouido OD). Figures in figures/ (including the Yeouido OD path plots) are within the approved export scope. Researchers can apply to the data provider for access.

재현 방법How to reproduce

  1. 원자료 접근 승인을 받고 입력 파일을 data/restricted/(또는 환경변수 RAW_DIR)에 둡니다. 필요한 파일 이름은 각 스크립트 상단 RESTRICTED DATA REQUIRED 주석과 code/*/README.md에 있습니다.Obtain access and place inputs under data/restricted/ (or set RAW_DIR). Required file names are in each script's RESTRICTED DATA REQUIRED header and in code/*/README.md.
  2. 저장소 최상위에서 실행합니다(예: Rscript code/03_road_scm/run_nested53_abadie2015_placebo.R). 출력은 output/에 생기며 git에서 제외됩니다.Run from the repository root (e.g. Rscript code/03_road_scm/run_nested53_abadie2015_placebo.R). Outputs go to output/, which is git-ignored.
  3. 실행 순서는 폴더별 README를 따르고, 결과를 results/와 비교합니다.Follow each folder's run order and compare with results/.

한계Limitations

  • 원자료 비공개.Restricted data. ①②④는 반출 제한 자료가 있어야 다시 실행할 수 있습니다.①②④ cannot be rerun without the restricted data.
  • 요인 수 민감도(①).Rank sensitivity (①). r = 4에서 +1.568%, r = 1에서 +0.27%.+1.568% with r = 4 but +0.27% with r = 1. rank_sensitivity.csv
  • 다중비교(③).Multiple testing (③). 12개 링크를 각각 검정하며, 위약 53개라 p의 최솟값이 1/54 ≈ .019입니다. 도너가 서울 밖이라 지역별 충격이 다를 수 있습니다.12 links are tested separately and the minimum attainable p is 1/54 ≈ .019; donors outside Seoul may face different shocks.
  • 단일 처치 단위(④).Single treated unit (④). 시점 위약에서도 +1.6~2.4%의 양의 격차가 나타나 효과 크기는 신중히 해석해야 합니다.In-time placebos show +1.6–2.4% gaps, so the magnitude should be read cautiously.
  • 진단 실패(⑤).Failed diagnostics (⑤). 사전 기간 위약 검정이 기각되어 기술적 결과로만 씁니다.Pre-period placebo tests reject; descriptive only.
  • 결과 파일 세대 차이.Mixed result generations. results/03_road_scm/summary/road_placebo_p_all_vs_tau5.csv와 road_loo_cf.csv는 이전 사양(위약 도너에 처치 단위 미포함) 값이고, 본 결과는 road_abadie2015_placebo_loo_cf.csv·all_units_summary.csv입니다.road_placebo_p_all_vs_tau5.csv and road_loo_cf.csv in results/03_road_scm/summary/ come from the earlier specification; the headline results are road_abadie2015_placebo_loo_cf.csv and all_units_summary.csv.
  • 상류 스크립트 미포함.Upstream scripts not included. 일부 스크립트의 입력을 만드는 상류 파일(예: 패널·공변량 생성 스크립트)은 저장소에 없습니다. 폴더별 README에 목록이 있습니다.Files that build some scripts' inputs are not in the repository (e.g. panel and covariate builders); see each folder README.
