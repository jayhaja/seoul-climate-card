기후동행카드(2024-01-27 시행)의 효과를 합성통제법(SCM)과 일반화 합성통제법(gsynth)으로 추정한 석사 논문의 공개 재현 자료입니다. 원자료(교통카드 OD)는 데이터안전센터 반출 제한 자료라 포함하지 않으며, 이 사이트의 수치는 모두 저장소 results/의 집계 CSV에서 가져왔습니다. Replication site for a master's thesis that estimates the effect of the Climate Companion Card (launched 27 Jan 2024) with synthetic control (SCM) and generalised synthetic control (gsynth). Raw smart-card OD data are export-restricted and not included; every number here comes from the aggregated CSVs in results/.

SCM 추론 규칙SCM inference rules

  • 검정통계량은 처치 후/처치 전 RMSPE 비율 (Abadie, Diamond & Hainmueller 2015).Test statistic: post-/pre-treatment RMSPE ratio (Abadie, Diamond & Hainmueller 2015).
  • 위약 도너 풀에 처치 단위를 포함하고, p = (1 + 처치보다 비율이 크거나 같은 위약 수) / (1 + 위약 수).The treated unit is included in each placebo's donor pool; p = (1 + #placebos with ratio ≥ treated) / (1 + #placebos).
  • 사전 적합도 필터 없음. 사전 RMSPE 5배 이하 위약만 쓰는 결과는 민감도.No pre-fit filter; restricting to placebos with pre-RMSPE ≤ 5× is a sensitivity check.
