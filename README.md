# Seoul Climate Card: effects on public transport use and car traffic

Replication materials (code, aggregated results, figures) for a thesis evaluating Seoul's Climate Companion Card (기후동행카드, launched 2024-01-27).

| Folder | Contents |
|---|---|
| `code/01_citywide_gsynth` | Generalized synthetic control (gsynth/fect) for 409 within-Seoul OD pairs |
| `code/02_heterogeneity` | Counterfactual-relative effects by neighbourhood characteristics |
| `code/03_road_scm` | Synthetic control for 12 directional road links around Yeouido |
| `code/04_yeouido_transit_scm` | Synthetic control for public transport from Yeouido-dong (79 donors) |
| `code/05_seoul_road_gsynth` | Seoul-wide road traffic gsynth (TOPIS sites) |
| `results/` | Aggregated estimates (CSV) matching the folders above |
| `figures/` | Thesis figures and diagnostic plots |
| `data/` | Data sources and access notes (raw smart-card data are not redistributed) |

This README is a placeholder; a full guide and an interactive site (`docs/`) are in progress.
